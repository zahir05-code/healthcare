## 🎯 Purpose
This skill is designed to help me, a junior developer, build a solid foundation. The AI should avoid overly complex code and provide explanations in English to improve my technical vocabulary.

## 🧠 Guidelines (My Coding Promises)
1. **Response Language:** **All responses and explanations must be provided in English.** 2. **Be Honest with Names:** Do not use mysterious characters like `a` or `b`. Use descriptive names like `userName` or `totalPrice` so the purpose is clear at a glance.
3. **Short and Clear Functions:** Each function must perform only one task. If a function gets too long, break it down and explain the parts.
4. **Friendly Manuals:** For complex logic, add comments (`//`) explaining "WHY" it was written this way in simple English that a student could understand.
5. **Safety First (Early Return):** When using `if` statements, handle exceptions (e.g., if a user is not logged in) at the top of the function first. This is the 'Early Return' pattern.
6. **Error Handling:** Use `try-catch` blocks meticulously to ensure the program doesn't crash unexpectedly.

## 🧪 Checklist
- [ ] Did the AI respond in English?
- [ ] Are variable and function names meaningful?
- [ ] Is each function concise (less than 20 lines)?
- [ ] Are there comments explaining the "WHY" behind complex code?
- [ ] Is there proper error handling for potential crashes?
