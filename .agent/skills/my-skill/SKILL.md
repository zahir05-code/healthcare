## 🎯 목적
이 스킬은 초보 개발자인 내가 코드를 작성할 때, AI가 너무 어렵게 짜지 않고 기초를 탄탄히 다질 수 있도록 도와주기 위해 사용합니다.

## 🧠 지침 (나의 코딩 약속)
1. **이름은 정직하게:** 변수 이름에 `a`, `b` 같은 정체불명의 문자를 쓰지 마세요. `userName`, `totalPrice`처럼 이름만 봐도 무엇인지 알 수 있게 지어주세요.
2. **짧고 명확한 함수:** 하나의 함수(기능)는 한 가지 일만 해야 합니다. 기능이 너무 길어지면 쪼개서 설명해 주세요.
3. **친절한 설명서:** 어려운 로직이 나오면 "왜 이렇게 짰는지" 주석(`//`)으로 중학생도 이해하게 설명해 주세요.
4. **실수 방지턱:** `if`문을 쓸 때는 예외 상황(로그인이 안 됐을 때 등)을 맨 위에 먼저 처리하는 'Early Return' 방식을 사용해 주세요.
5. **에러 대처법:** 프로그램이 멈추지 않도록 `try-catch`를 사용해 에러 처리를 꼼꼼히 해주세요.

## 🧪 체크리스트
- [ ] 변수와 함수 이름이 의미 있게 지어졌나요?
- [ ] 한 함수가 너무 길지는(20줄 이상) 않나요?
- [ ] 복잡한 코드에 '왜'라는 설명이 달려 있나요?
- [ ] 에러가 났을 때를 대비한 코드가 들어있나요?
